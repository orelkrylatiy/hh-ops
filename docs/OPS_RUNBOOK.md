# HH-ops: запуск и контроль

## Что такое один запуск

На VPS проект находится в `/home/ubuntu/hh-ops`. `all-profiles.sh` запускает
одну операцию сразу по профилям из `PROFILES` (параллельно, с блокировкой на
каждый профиль). Для текущего live-набора используются шесть профилей:
`0056 0555 1206 1558 5457 8755`. Профиль `0639` требует повторной авторизации
и в этот набор не входит.

Один `reply` запуск сам проходит чаты каждого профиля. Каждый профильный
worker по очереди обрабатывает подходящие чаты этого аккаунта. В чате он
передаёт Humanizer недавнюю историю и готовит один ответ, закрывающий все
неотвеченные вопросы работодателя после последнего ответа кандидата. Несколько
вопросов подряд обрабатываются в одном сообщении. Значение
`--chats 100` — максимум 100 чатов на профиль за один проход. `--rounds 1`
означает один проход; большее значение повторно сканирует чаты в рамках того
же запуска (разрешено от 1 до 5). `all-profiles.sh` запускает шесть профильных
workers вместе, поэтому шесть аккаунтов не требуют шести ручных команд.
VPS ограничивает параллелизм тремя профилями за раз, чтобы снизить burst
нагрузку на текстовый provider; все шесть профилей всё равно завершаются за
один цикл.

`boost` поднимает опубликованное резюме, `reply` отвечает на сообщения
работодателей, `apply` отправляет отклики на вакансии. Текущий VPS цикл
автоматически запускает только `boost` и `reply`.

## Ручной запуск

Подключиться и перейти в проект:

```bash
ssh sg
cd /home/ubuntu/hh-ops
```

Сначала можно посмотреть preview ответов без отправки:

```bash
PROFILES="0056 0555 1206 1558 5457 8755" /bin/bash scripts/all-profiles.sh reply --dry-run --chats 100 --rounds 1
```

Запустить live-ответы на всех шести профилях одной командой:

```bash
PROFILES="0056 0555 1206 1558 5457 8755" /bin/bash scripts/all-profiles.sh reply --live --chats 100 --rounds 1
```

Поднять резюме по всем шести профилям:

```bash
PROFILES="0056 0555 1206 1558 5457 8755" /bin/bash scripts/all-profiles.sh boost --live
```

Один полный production-цикл (boost, затем reply) запускается так:

```bash
/home/ubuntu/bin/hh-ops-reply-boost cycle
```

## Повтор вопроса работодателя

Сравнивается точный текст после нормализации пробелов и пунктуации. При первом
точном повторе вопроса (второе появление того же текста) проект отвечает
`Да` по-русски, без точки. Если тот же вопрос появляется ещё раз (третье появление),
чат попадает в ручную очередь и автоматические ответы прекращаются. Повтор
не-вопроса, кнопка или структурированное действие также остаются ручными.

## Расписание VPS

Cron запускает `cycle` в 09:00, 14:00 и 19:00 по Москве (06:00, 11:00 и 16:00
UTC). Каждый цикл сначала пробует поднять опубликованные резюме, затем
обрабатывает чаты по всем шести профилям. Интервал между boost составляет
пять часов; [справка hh.ru](https://feedback.hh.ru/knowledge-base/article/0012145?hhtmFrom=main&hhtmFromLabel=simular)
указывает, что ручное бесплатное поднятие доступно раз в четыре часа. По
времени Алматы (UTC+5) это 11:00, 16:00 и 21:00.

Посмотреть расписание:

```bash
crontab -l
```

Посмотреть последние результаты:

```bash
tail -n 100 /home/ubuntu/hh-ops/logs/cron.log
tail -n 80 /home/ubuntu/hh-ops/logs/profiles/0056-reply.log
```

Замените `0056` в имени профильного лога на `0555`, `1206`, `1558`, `5457` или
`8755`, чтобы посмотреть другой аккаунт. В live-итоге `sent` — отправлено,
`manual` — оставлено человеку, `errors` — ошибка. `HH_RUN_END ... status=0`
означает, что профиль завершил операцию успешно.

На сервере:

```bash
cd /home/ubuntu/hh-ops
git status --short --branch
git pull --ff-only
```

Cron управляется пользователем `ubuntu`. Чтобы приостановить будущие циклы,
откройте `crontab -e` и закомментируйте строки блока `HH-OPS`; не удаляйте
остальные задания cron.
